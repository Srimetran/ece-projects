# Principles of Electrical Engineering I Projects

Hands-on circuit design and measurement projects spanning resistive networks, operational amplifiers, circuit theorems, data conversion, and Arduino-controlled analog systems.

## Projects

| Project | Focus |
| --- | --- |
| Ohm's Law & Arduino Measurement | Voltage/current measurement, resistance, breadboarding, Arduino instrumentation |
| Resistive Networks & Voltage Division | Series/parallel networks, equivalent resistance, voltage division, proportionality, LTspice |
| Automatic Light Sensor | Photoresistor sensing, op-amp comparison, LED control |
| Operational Amplifier Circuits | LM741, negative feedback, inverting/non-inverting amplification, gain and saturation |
| Circuit Network Analysis | Superposition, Thevenin and Norton equivalents, experimental verification |
| R-2R Digital-to-Analog Converter | 4-bit DAC, R-2R ladder, Arduino, analog waveform generation |
| Programmable Constant-Current Source | R-2R DAC, op-amp circuitry, current sensing, Arduino feedback/control |

These projects originated from Principles of Electrical Engineering I laboratory work at Rutgers University. Collaborative experiments are presented as collaborative work, and the descriptions focus on the designs, measurements, and implementations represented in the original lab materials.
