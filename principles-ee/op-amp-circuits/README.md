# Operational Amplifier Circuits

## Overview

Designed and tested circuits based on the LM741 operational amplifier, including amplifier configurations used to study closed-loop gain, feedback, and output limitations.

## Inverting Amplifier

For an ideal inverting amplifier, the closed-loop voltage gain is determined by the resistor ratio:

```
Av = -Rf / Rin
```

The negative sign represents the 180-degree inversion between input and output. Resistor values were selected to achieve a specified gain while the op-amp was powered from positive and negative supply rails.
