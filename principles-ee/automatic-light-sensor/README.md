# Automatic Light Sensor

## Overview

Built an automatic light-control circuit using a photoresistor, an operational amplifier, and an LED. The circuit responds to ambient light level and switches the LED based on the voltage produced by the light-dependent sensing network.

## How It Works

A photoresistor changes resistance as lighting conditions change. This resistance change alters a voltage in the sensing network. An op-amp compares the light-dependent signal against a reference level, allowing the circuit to control the LED according to the surrounding light condition.

## Engineering Concepts

- Photoresistors / light-dependent resistors
- Sensor interfacing
- Voltage-divider behavior
- Operational amplifiers
- Threshold-based control
- Analog-to-digital decision behavior
- Breadboard implementation and measurement
