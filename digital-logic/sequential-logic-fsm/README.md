# Sequential Logic & Finite State Machines

## Overview

Designed and simulated fundamental sequential logic elements before applying them to a finite-state machine. The project covered SR latches, D latches, D flip-flops, testbenches, waveform verification, state equations, and state-transition behavior.

## Design Work

The sequential elements were represented in Verilog and evaluated using generated schematics and simulation waveforms. A simple state machine was then developed from excitation equations and a state-transition table, connecting low-level storage elements to higher-level sequential system behavior.

## Key Takeaways

- SR and D latch behavior
- Edge-triggered D flip-flops
- Verilog modeling of sequential logic
- Testbench construction
- Waveform-based verification
- Excitation and transition equations
- State tables and state diagrams
- Finite-state-machine fundamentals

**Context:** Collaborative Digital Logic Design laboratory project.
