# Digital Logic Design Projects

A collection of digital hardware projects exploring the progression from fundamental logic gates to combinational circuits, arithmetic hardware, sequential logic, and finite-state-machine controllers.

## Project Collection

| Project | Focus |
| --- | --- |
| Logic Circuit Design & Optimization | Boolean functions, 74LS gates, breadboarding, gate-count optimization |
| Combinational Logic & Hazard Analysis | Karnaugh maps, NAND logic, timing hazards |
| Multiplexer-Based Gray Code Converter | 8:1 multiplexers, Gray code, Verilog, simulation |
| 4-Bit Arithmetic Logic Unit | Arithmetic hardware, multiplexers, two's complement, overflow |
| Sequential Logic & Finite State Machines | Latches, flip-flops, testbenches, state transitions |
| Traffic Signal Controller | FSM design, 555 timer, state storage, hardware debugging |

These projects were completed collaboratively as part of Digital Logic Design laboratory work. Individual project pages summarize the design approach and results preserved in the original reports.
