# Multiplexer-Based Gray Code Converter

## Overview

Designed combinational MSI circuits around an 8-to-1 multiplexer and used multiplexers to implement binary/Gray-code conversion logic. The design was represented in Verilog and verified through schematic-level simulation.

## Implementation

An 8-to-1 multiplexer module used a three-bit select input to choose one of eight data inputs. Multiple instances were then used to generate the output bits of a three-bit code converter.

The project included logic diagrams, Verilog design work, a synthesized schematic, simulation waveforms, Karnaugh-map analysis, and Boolean-algebra derivations.

## Key Takeaways

- 8-to-1 multiplexer design
- Hierarchical digital design using reusable modules
- Verilog HDL
- Binary and Gray-code relationships
- Karnaugh maps and Boolean algebra
- Schematic and waveform-based verification

**Context:** Collaborative Digital Logic Design laboratory project.
